# 🧠 Face Processing AI

## 📌 About the Project

Face Processing AI is a **Streamlit-based computer vision application** that performs different face and image processing techniques.

# DEMO LINK
https://face-processing-tyomdjxjkfhjeswgjkutsy.streamlit.app/

## 🔹 Features

* 🔍 **Template Matching** – Finds a template inside an image.
* 👤 **Viola-Jones** – Detects faces using Haar Cascade.
* 🧠 **DeepFace** – Analyzes age, gender, and emotion.
* 🔐 **FaceNet** – Compares two faces using facial embeddings.

## 🛠️ Technologies Used

* Python
* Streamlit
* OpenCV
* NumPy
* Pillow
* DeepFace
* FaceNet

## ▶️ How to Run

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

## 🎯 Objective

The main objective of this project is to demonstrate different **image processing, face detection, facial analysis, and face verification techniques** using Python.
